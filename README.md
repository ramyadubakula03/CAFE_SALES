# ☕ Cafe Sales Analysis

## 📌 Project Overview

The **Cafe Sales Analysis** project focuses on analyzing cafe transaction data to understand sales performance, customer purchasing patterns, product preferences, and business trends.

The objective is to transform raw sales data into meaningful insights through data cleaning, exploratory data analysis (EDA), and data visualization.

This analysis helps identify best-selling products, peak sales periods, revenue trends, and opportunities for improving cafe business performance.

## 🎯 Business Problem

Cafe businesses generate large amounts of transaction data every day. However, understanding which products generate the highest revenue, when customers purchase the most, and which categories perform best can be challenging.

**Objective:** Analyze cafe sales data to identify important business patterns and provide actionable insights that can help improve sales, optimize product offerings, and support better business decisions.

## 📂 Dataset Information

The dataset contains cafe transaction records with information about sales, products, quantities, and transaction details.

### Dataset Columns

| Column | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Item | Product purchased |
| Quantity | Number of items purchased |
| Price Per Unit | Price of one item |
| Total Spent | Total transaction amount |
| Payment Method | Method of payment |
| Location | Transaction location |
| Transaction Date | Date of transaction |

## 🧹 Data Cleaning & Preprocessing

The following data preprocessing activities were performed:

- Identifying and handling missing values.
- Checking and removing duplicate records.
- Handling inconsistent categorical values.
- Correcting incorrect data types.
- Identifying and treating outliers.
- Validating numerical columns.
- Creating additional features where required.
- Preparing the dataset for exploratory analysis.

## 📊 Exploratory Data Analysis (EDA)

### 1. Univariate Analysis
- Distribution of product sales.
- Frequency of payment methods.
- Quantity distribution.
- Revenue distribution.
- Analysis of categorical and numerical columns.

### 2. Bivariate Analysis
- Product vs Total Sales.
- Payment Method vs Total Spent.
- Quantity vs Total Spent.
- Transaction Date vs Sales.
- Location vs Revenue.

### 3. Multivariate Analysis
- Product, Quantity, and Revenue comparison.
- Payment Method and Location analysis.
- Sales trends across different time periods.
- Relationships between multiple numerical features.

## 📈 Key Business Analysis Areas

- Customer purchasing patterns.
- Popular payment methods.

- Sales performance by location.
